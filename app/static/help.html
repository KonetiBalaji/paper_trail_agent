Get started with Paper Trail Agent

Try the free synthetic demo

  1. Open the app and start a private demo session.
  2. Choose a fictional case. Try the $25 interest discrepancy or the $50 total error.
  3. Open a cited source, inspect the calculation, and save a review decision.
  4. Export a redacted checklist if you want to keep the example.

Use a private workspace

Ask your workspace administrator for a reviewer or viewer account. Reviewers can upload supported statements and record decisions. Viewers can inspect saved evidence and exports.

Read the data-use notice in the app before uploading. The public demo uses fictional statements.

Get help

Check service status if a request fails. For a reproducible app bug, open a GitHub issue with synthetic inputs, the expected result and the result you saw. Keep personal statements, account identifiers and credentials out of public issues.
