# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/KonetiBalaji/paper_trail_agent/security/advisories/new)
when available. If it is unavailable, contact the repository owner privately
through an existing verified channel. Do not post credentials, account numbers,
customer PDFs, exploit instructions or personal data in a public issue.

Include the affected commit or deployment, a synthetic reproduction, the
expected boundary and observed response, and impact. Avoid accessing another
person's records, triggering paid model calls, flooding the service or deleting
data. The public judge demo supports fictional fixtures only.

The maintainer is the incident owner. There is currently no staffed response
team or guaranteed response SLA. Only the current `main` deployment is actively
maintained. Please coordinate disclosure privately before publishing details.

Current controls, evidence limits and response procedure:
[Security verification](docs/SECURITY-VERIFICATION.md),
[Incident response](docs/INCIDENT-RESPONSE.md).
